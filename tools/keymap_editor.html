3选择 HID 键值

列表与固件 ui_pages2.c 的 s_hid_usage[] 完全一致（83 项），设备上旋转编码器能选的键值就是这些。 写入 0x00 表示该键不映射任何键。
LCtrl / RShft 这类是修饰键： 选中后按键只发 modifiers 字节里的位、不占 6 个键码槽位， 按住它再按别的键就是组合键。

4批量与数据管理

M键盘宏（一个键触发一串按键）

宏 = 把一连串按键编成"步骤"，绑到某个物理键上：按一下那个键，键盘自己按顺序敲出来。 每步可以是单键，也可以是组合键（如 Ctrl+C）；每步之间 45ms； 一共 4 个宏，每个最多 8 步。绑定按映射组分开，现在编的是 第 1 组 的绑定。
注意：设备要跑支持宏的固件（协议次版本 ≥ 2）；连上设备后可在 「设备直连」里点「自检」看是否认识宏命令。

连不上？按这四步看：
① 键盘必须插着 USB 线（走蓝牙连电脑是连不上的，这条通道就是那根 USB 线里的虚拟串口）； ② 打开「设备管理器 → 端口(COM 和 LPT)」，应该能看到 「USB 串行设备 (COMx)」；如果显示成「无法识别的 USB 设备」或压根没有， 右键把它卸载设备（勾上"删除驱动程序"）再重新插拔一次 USB —— Windows 会把上一次「纯 HID 键盘」的描述符缓存住，固件改成 HID+CDC 复合设备后必须让它重新枚举； ③ 端口被别的程序占着（MRS 的串口监视器、WCHISPTool、另一个浏览器标签页）——先全部关掉； ④ 用 Chrome / Edge 打开本页（Firefox / Safari 没有 Web Serial；IDE 内置浏览器也不行）。

6遥控模式配置（三张表）

CH592X 当遥控器用时，按了哪个键就发一个动作编号给从机（CH570Q）； 从机收到后查自己的 Flash 执行，具体做什么动作和主机无关。 这里配的是主机侧的三张表：

  • ① 动作目录 —— 编号 → 名称。只为在屏幕上提示用户"这个键是什么功能"。
  • ② 动作编号表 —— 表名 + 12 个动作编号（9 个按键 + 编码器左转/右转/单击）。可以有多张，按表名区分。
  • ③ 设备绑定 —— 设备名 → 用哪张表。决定"操作哪台从机时用哪套编号"。

未读取（先在上面「设备直连」里连上 USB，再点「从设备读取」）。

①动作目录 编号 1~63 · 名称 ≤10 个字母/数字（只能 ASCII，屏上是点阵字库）
②动作编号表 每张表 12 个编号，对应 K1~K9 + 左转/右转/单击
③设备绑定 设备名（从机自己 Flash 里固定的） → 用哪张表

怎么用：连上 USB → 「从设备读取」把现状读回来 → 改 → 「写入设备」。 每张表写好编号后记得点「写入设备」，否则掉电就没了。
编号下拉和手打都行：下拉是从「① 动作目录」里选（自动填编号）， 也可以直接在数字框里手打编号；打了目录里没有的编号会标红提醒 —— 从机照样执行，只是主机屏幕上显示不出名字。

      如何应用到工程
      

        

          第 1 步 · 替换映射表（所有改动都需要）

          打开 hardware/key_matrix.c，找到
          static const uint16_t s_map_default[...]，
          连它下面的 s_map_name[] 一起，整块换成「映射表」标签页生成的代码。
        

        

          第 2 步 · 组合键 / 修饰键（本版固件已内置，不用改代码）

          ui_kbd.c 会把映射值高字节当修饰位、把 0xE0~0xE7
          当单个修饰键，USB / 2.4G / BLE 三条通道都走这套。
          做完第 1 步（或直接用「设备直连」下发）即可生效，
          说明见「组合键说明」标签。
        

        

          第 3 步 · 编译烧录

          MounRiver Studio 重新编译。运行时 KEY_ResetMap()
          会用新默认值覆盖，行为一致。
        

        

          注意：KEY_MAP_GROUPS 决定组数（当前 5）。
          若在 key_matrix.h 里改过，请同步改本页脚本开头的
          const KEY_MAP_GROUPS = 4。
        

      

    


    

      编码格式与兼容性
      

        

          映射值 uint16_t 的编码：高字节 = 修饰键位图，低字节 = 主键。
          这与 HID 报文的 [modifiers][key] 布局一致。
        

        

          本版固件：UiKbd_UsageOf() 取低字节当主键、
          UiKbd_ModsOf() 取高字节当修饰位，所以
          0x0106（Ctrl+C）这类值下发后立刻生效，
          USB / 2.4G / BLE 三条通道都支持。

          向后兼容：纯单键的值都在 0x00~0xFF，旧固件照常工作；
          旧固件会把带高字节的组合键当成"无键"，升级本版固件后即恢复。
        

        

          修饰键位定义（与固件 HID 报文第 0 字节一致）：

          0x01 LCtrl · 0x02 LShift ·
          0x04 LAlt · 0x08 LGUI

          0x10 RCtrl · 0x20 RShift ·
          0x40 RAlt · 0x80 RGUI
        

        

          单独一个修饰键：低字节直接写 0xE0~0xE7
          （列表里的 LCtrl 等），或者用高字节写法 0x0100
          （只按 LCtrl）都行，固件两种写法都认。
        

      

    


    

      HID 键值速查
      

        

          字母：A–Z = 0x04–0x1D

          数字：1–9 = 0x1E–0x26，0 = 0x27

          编辑键：Enter 0x28、Esc 0x29、
          Backspace 0x2A、Tab 0x2B、
          Space 0x2C、CapsLock 0x39

          功能键：F1–F12 = 0x3A–0x45

          导航键：Ins 0x49、Home 0x4A、
          PgUp 0x4B、Del 0x4C、
          End 0x4D、PgDn 0x4E

          方向键：右 0x4F、左 0x50、
          下 0x51、上 0x52

          小键盘：Num1–Num9 = 0x59–0x61

          媒体键：音量+ 0x80、音量- 0x81

          修饰键：LCtrl 0xE0、LShift 0xE1、
          LAlt 0xE2、LGUI 0xE3、
          RCtrl 0xE4、RShift 0xE5、
          RAlt 0xE6、RGUI 0xE7
